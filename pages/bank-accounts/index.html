  3. Paste the token below. Each token works once. If this fails after SimpleFIN accepted it, make a new one.

Category rules

A rule sorts every transaction whose payee or description mentions its text (capitals don't matter), past and future. Rules higher in the list win. A category set by hand on a transaction always beats a rule, and setting one teaches the portal that payee: it adds a rule for it automatically.

Import from Quicken

  1. In Quicken, choose File › Export › Quicken Interchange Format (.QIF) File. Pick the account and the dates, and tick Transactions and Category list.
  2. Choose that file here, and the account it belongs to.
  3. Preview shows exactly what will happen. Nothing is saved until you press Import.

Transactions from before the bank feed starts are added with their Quicken category. In the period the feed already covers, nothing is added twice: each Quicken entry is matched to the feed's transaction and only its category is copied over, never replacing one you set by hand.
