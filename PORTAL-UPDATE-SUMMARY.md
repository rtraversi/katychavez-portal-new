# Portal Update Summary
_Last updated: July 11, 2026_

A plain-English rundown of what's new, what's coming, and what we're building right now.

---

## ✅ Recently Built — ready to roll out

### 📁 Folders now sort alphabetically
Your document folders (and everything inside them) now list in clean A–Z order, so files are
easier to scan and nothing feels randomly placed. "All Files" stays pinned at the top.

### 🗂️ Subfolders (folder tree)
You can now nest folders inside folders — an expandable tree — and organize documents to match
how the firm actually works. Add a subfolder, rename, or delete right where you're working, with
file counts shown at each level. Selecting a folder shows everything inside it, including nested items.

### ✍️ Signatures for every staff member
Signatures used to be one firm-wide signature that only the owner could set. Now **each person has
their own signature** — attorneys and paralegals alike. On the signing tool you can also pick whose
signature to apply (for example, a paralegal applying an attorney's signature), and the Settings page
is now simply **"My Signature."**

### 🛡️ Smarter conflict checks — catches prior inquiries
The conflict checker now searches **past inquiries**, not just existing clients and opposing parties.
So if someone called about representation last week — even if they never hired the firm and there's no
file on them — running a check on the other spouse will now **flag that prior contact**. This closes a
real ethics gap (a prospective-client consultation can conflict the firm out of the other side). Prior
inquiries show up as a clear, highlighted "Prior Inquiry" alert with who checked it and when.

---

## 📌 Planned & Locked In — scoped and ready to build

### 📄 Helpful Hints included with every intake
A firm **Library** where staff upload and manage their own reference documents (Helpful Hints,
process sheets, firm info) — separate from client files. Tag each Helpful Hints sheet to a case type,
and the right one automatically goes out with each intake. _(One quick decision pending: send it as a
link in the email vs. attached as a file.)_

### 🔏 Send a document for e-signature to anyone
Today e-signatures only go to existing portal clients. This would let staff **upload a document and
send it to any email address** for signing — useful for opposing counsel, third parties, etc. Fully
scoped and on the shelf; we're weighing the security trade-offs before committing to build it.

### 🔎 Discovery Manager
A larger module for family-law financial discovery — ingesting, organizing, and analyzing financial
documents. Scoped and waiting on a few real sample document sets before we finalize and build.

---

## 🚧 Building Now

### 📅 Online consultation scheduling — built into the portal
Clients and prospects will be able to **see real availability and book a consult** directly, pulling
from the attorneys' Outlook calendars so there's never a double-booking. Three consult types
(free, paid, and reduced-rate), with a payment link the office can send for the paid ones. This is
the current priority and work starts now.
